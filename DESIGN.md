# AICP Public Showcase — DESIGN.md
## Visual Theme
Technical, cinematic, editorial, precise. The interface should feel like an AI control room rather than a SaaS template.
Avoid generic AI gradients, nested cards, excessive rounded containers, icon tiles, stock illustrations, and dashboard clutter.

## Color Roles
- Void: #070A0C — page background.
- Surface: #0B1113 — major interactive surfaces.
- Text: #EEF5F4 — primary text.
- Muted: #91A09F — secondary copy.
- Signal Cyan: #8DF4FF — primary interaction and system signal.
- Signal Acid: #C9FF63 — verified / healthy state.
- Signal Amber: #FFB15C — waiting / attention.
- Grid: #243037 — structural borders.

## Typography
Use Manrope for display/body and DM Mono for technical metadata, labels and evidence.
Large headlines are compact, editorial and asymmetric. Technical labels are uppercase with generous tracking.

## Layout
Use wide asymmetric compositions, strong negative space, thin structural rules and deliberate vertical rhythm.
The live chat is a first-class product surface, not a footer widget. It must be reachable from the primary navigation and hero CTA.

## Interaction
Motion should communicate system state. Prefer slow orbital motion, restrained hover transitions and meaningful status changes. Respect reduced-motion preferences.
Chat states must be honest: connecting, connected, thinking, error.

## 3D Direction
The AICP core visualization is procedural and code-first: a luminous control core, worker nodes, links and an orbital ring. It is decorative architecture, not a fake telemetry dashboard.

## UX Guardrails
- Never expose credentials.
- Never claim private telemetry is public.
- Never show fake live metrics as real measurements.
- Preserve keyboard access and visible focus.
- Chat errors remain understandable and recoverable.

## Verification
Before publication: desktop + mobile screenshot review, browser console check, responsive layout check, and a real chat request through the public Worker.
